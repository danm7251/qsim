# Roadmap
A rough outline of where the development of `qsim` will go. Subject to change.

## Pre-Alpha
- [x] Support a universal gate set.
- [x] Support AVX and FMA acceleration.
- [ ] Expand hardware acceleration to measurement.
- [ ] Support QFT subroutine and SWAP gate.
- [ ] Expand circuit representation to result collection.
- [ ] Achieve full doc coverage of public API.
- [ ] Create release (CD) workflow.

## Post-Alpha
- [ ] Add gate fusion.
- [ ] Add parallelism.
